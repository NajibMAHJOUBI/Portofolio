Extension Snowflake pour VS Code

L’extension Snowflake pour Visual Studio Code permet d’écrire, d’exécuter et de gérer du SQL Snowflake directement depuis VS Code, tout en intégrant Snowpark Python et les Native Apps. Elle constitue un outil important pour les développeurs, data engineers et utilisateurs avancés.

✅ 1. Fonctionnalités principales de l’extension

✔ Écriture et exécution de SQL Snowflake

  • Exécuter des requêtes SQL directement dans VS Code.
  • Résultats visibles dans un panneau dédié. [docs.snowflake.com]

✔ Support Snowpark Python

  • Debugging
  • Syntax highlighting
  • Autocomplétion pour SQL dans le code Python Snowpark [docs.snowflake.com]

✔ Développement Native Apps

  • Création, déploiement, exécution et suppression d’applications Native Apps.
  • Gestion des environnements et variables. [marketplac...studio.com]

✔ Object Explorer

  • Naviguer dans les bases, schémas, tables, vues, fonctions, etc.
  • Copier rapidement des noms d’objets. [marketplac...studio.com]

✔ SnowConvert Migration Assistant

  • Résolution d’erreurs de migration SQL avec aide IA.
  • Intégré via panneaux, CodeLens ou chat interactif. [marketplac...studio.com]

✔ Gestion multicomptes et sessions

  • Connexion à plusieurs comptes Snowflake.
  • Sélection du rôle, warehouse, base, schéma, secondary roles. [marketplac...studio.com]

✅ 2. Installation de l’extension

Deux méthodes sont disponibles :

🔹 A. Depuis le Visual Studio Marketplace

  • VS Code → Settings > Extensions
  • Rechercher Snowflake
  • Identifier l’extension via le badge Snowflake
  • Sélectionner Install [docs.snowflake.com]

🔹 B. Via un fichier .vsix

  • Aller sur : https://marketplace.visualstudio.com/items?itemName=snowflake.snowflake-vsc
  • Télécharger la version du .vsix depuis « Version History »
  • VS Code → Extensions > More (…) > Install from VSIX
  • Sélectionner le fichier téléchargé [docs.snowflake.com]

✅ 3. Connexion à Snowflake

Avant toute exécution SQL ou Snowpark, une connexion Snowflake est requise.

Méthodes de connexion supportées :

  • ✔ Username / Password
  • ✔ SSO / SAML
  • ✔ Key-pair authentication
  • ✔ OAuth via fichier connections.toml [docs.snowflake.com]

Première connexion :

  • a. Cliquer sur l’icône Snowflake dans l’Activity Bar
  • b. Saisir l’account identifier ou l’URL Snowflake
  • c. Choisir la méthode d’authentification [docs.snowflake.com]

Après première connexion, l’account identifier peut ne plus être demandé.

✅ 4. Fichier de configuration connections.toml

L’extension permet :

  • d’ajouter et modifier des connexions,
  • de gérer plusieurs environnements,
  • de stocker les paramètres de connexion. [docs.snowflake.cn]

Méthode d’édition dans VS Code :

Activity Bar → Account → Snowflake: Edit Connections File
