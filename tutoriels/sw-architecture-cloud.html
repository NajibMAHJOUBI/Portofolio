Snowflake Data Engineering Cloud

Objectifs du tutoriel

Principes clés concernant l’hébergement sur plateformes Cloud

Snowflake fonctionne nativement et uniquement dans le cloud

Toutes les couches de l’architecture Snowflake (stockage, compute, cloud services) sont déployées sur la plateforme cloud choisie.

Le choix du cloud est indépendant pour chaque compte Snowflake

Votre organisation peut :

  • héberger différents comptes Snowflake sur différentes plateformes,
  • choisir un cloud différent de ses autres services internes.

Le coût varie selon la région + plateforme

Les crédits et coûts de stockage dépendent de la région sélectionnée.

Principes clés concernant l’hébergement sur plateformes Cloud

Chaque plateforme propose plusieurs régions Snowflake, où les comptes peuvent être provisionnés. (Fournisseurs → Régions Snowflake disponibles)

Autres points importants :

  • Une région = emplacement géographique physique défini par AWS, Azure ou GCP.
  • Le choix de la région affecte :
    • latence
    • conformité / légal
    • coûts
    • possibilité de réplication entre régions

Limitations selon Cloud Platform

Google Cloud

  • Support limité pour Private Service Connect.
  • Certaines fonctions système non disponibles.

Azure

  • Limitations sur Private Link dans certains cas.
  • Format "account name URL" non supporté pour tous les clients en connectivité privée.

AWS

  • Restrictions spécifiques dans les régions gouvernementales (ex. accès externe depuis UDF).

1. Définition

Snowgrid est la couche de connectivité globale de Snowflake qui permet :

  • Une expérience unifiée sur toutes les régions et clouds (AWS, Azure, GCP).
  • La mobilité des données entre régions/clouds.
  • La collaboration sécurisée à grande échelle.
  • La résilience cross‑cloud (failover, réplication).

C’est ce qui transforme Snowflake en un Data Cloud global plutôt qu’une simple base de données dans un cloud.

2. Fonctionnalités clés de Snowgrid

✔ 1. Cross‑Cloud Business Continuity

Permet d’assurer la continuité d’activité grâce à :

  • Replication : copie des bases, warehouses, objets de compte vers une autre région/cloud.
  • Failover / Failback : bascule contrôlée vers une région secondaire en cas d’incident.
  • Client Redirect : redirection automatique des connexions vers la région de secours.

Objectif : réduire RTO/RPO et garantir la disponibilité mondiale.

2. Cross‑Cloud Data Governance

Snowgrid assure une gouvernance cohérente dans toutes les régions :

  • Politiques de sécurité uniformes
  • Contrôles d’accès centralisés
  • Traçabilité et audit global
  • Respect des contraintes de résidence des données

3. Global Data Sharing

Grâce à Snowgrid, Snowflake permet :

  • Secure Data Sharing entre régions et clouds
  • Listings globaux sur le Marketplace
  • Collaboration sans copie de données

Les données restent dans leur région d’origine mais sont accessibles globalement.

4. Global Directory Services

Snowgrid maintient un répertoire global des comptes Snowflake :

  • Permet de partager des données avec n’importe quel compte Snowflake dans le monde
  • Gère les identités, les métadonnées et les autorisations de manière centralisée

3. Composants Snowgrid

Composant Rôle
Replication Copie des bases, objets, et métadonnées vers une autre région/cloud
Failover / Failback Bascule manuelle ou automatisée vers une région secondaire
Client Redirect Redirection automatique des connexions en cas de failover
Global Services Gouvernance, sécurité, identités, répertoire global
Cross-Cloud Sharing Partage de données sans copie entre clouds/régions
Marketplace Global Accès mondial aux listings de données et apps

4. Cas d'usages typiques

Multi‑cloud / Multi‑région

  • Répondre aux exigences de résidence des données
  • Réduire la dépendance à un seul cloud provider
  • Optimiser les coûts selon les régions

Résilience & Disaster Recovery

  • Réplication automatique
  • Bascule rapide en cas d’incident
  • Continuité d’activité mondiale

Collaboration globale

  • Partage de données avec partenaires internationaux
  • Marketplace mondial
  • Clean Rooms multi‑cloud
