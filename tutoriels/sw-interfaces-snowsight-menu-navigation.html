1. Objectif du Snowsight Navigation Menu

Le menu Snowsight regroupe les fonctionnalités Snowflake par grandes familles d'usage, afin de rendre la navigation plus intuitive.

2. Structure générale du nouveau menu Snowsight

Le menu Snowsight est organisé autour de catégories principales :

1) Work with data

La zone de développement et d'analyse des données.

Inclut :

  • Projects : Worksheets, Notebooks, Streamlit, Dashboards, Native Apps
  • Ingestion : Connectors, Add Data, Openflow, migrations de données
  • Transformation : Dynamic Tables, Tasks, jobs de transformation
  • AI & ML : Snowflake Cortex AI, Snowflake ML pour traitement, modèles, agents
  • Monitoring : Query history, job history, container services, logs/traces
  • Marketplace : Explorer et consommer données, apps & agents tiers

2) Horizon Catalog

Zone centrée catalogue et partage.

Inclut :

  • Catalog : Explorer bases, objets, data products de l'organisation
  • Data sharing :
    • Internal Marketplace
    • Private Sharing
    • Provider Studio

3) Governance & security

Pour gérer la sécurité, les permissions et la gouvernance.

Inclut :

  • Gestion des permissions & rôles
  • Contrôle des accès
  • Politiques de sécurité (masquage, accès en ligne, tags)

4) Manage

Zone d'administration.

Inclut :

  • Compute : Warehouses, Compute Pools
  • Admin :
    • Billing,
    • Contacts admin,
    • Intégrations,
    • Administration globale des comptes
