Snowflake Semi-structured JSON

✅ 1. Parsing : transformation du texte JSON/XML → VARIANT

✔ Fonctions principales

  • PARSE_JSON — convertit une chaîne JSON en VARIANT
  • CHECK_JSON — valide qu'une chaîne est un JSON correct
  • JSON_EXTRACT_PATH_TEXT — extraire un élément textuel via un chemin JSON
  • PARSE_XML, CHECK_XML — équivalents pour XML
  • STRIP_NULL_VALUE — nettoie les valeurs nulles JSON/XML
Points clés pour SnowPro Core :
  • PARSE_JSON() → renvoie toujours un VARIANT.
  • Si JSON invalide : échec ; pour tolérance aux erreurs → TRY_PARSE_JSON()
  • JSON NULL ≠ SQL NULL (dans VARIANT).

✅ 2. Création & manipulation d'ARRAY (ARRAY_*)

✔ Fonctions essentielles

  • ARRAY_CONSTRUCT, ARRAY_CONSTRUCT_COMPACT
  • ARRAY_APPEND / ARRAY_PREPEND
  • ARRAY_CAT — concaténer deux ARRAY
  • ARRAY_COMPACT — supprimer NULL
  • ARRAY_CONTAINS — vérifier présence d'un élément
  • ARRAY_DISTINCT — valeurs uniques
  • ARRAY_FLATTEN — réduire profondeur
  • ARRAY_GENERATE_RANGE — générer une séquence numérique
  • ARRAY_SIZE, ARRAY_SLICE, ARRAY_SORT
  • ARRAY_TO_STRING — transformer ARRAY en chaîne
  • ARRAY_UNION_AGG, ARRAY_UNIQUE_AGG — agrégations ARRAY

✅ 3. Création & manipulation d'OBJECT (OBJECT_*)

✔ Fonctions clés

  • OBJECT_CONSTRUCT — construire un OBJECT à partir de paires clé/valeur
  • OBJECT_CONSTRUCT_KEEP_NULL — version conservant les nulls
  • OBJECT_DELETE, OBJECT_INSERT, OBJECT_PICK
  • OBJECT_AGG — agrégation en OBJECT
  • OBJECT_KEYS — lister les clés d'un OBJECT

✅ 4. Fonctions de MAP (structured MAP)

  • MAP_CAT — concaténer deux MAP
  • MAP_CONTAINS_KEY
  • MAP_DELETE, MAP_INSERT
  • MAP_KEYS, MAP_PICK
  • MAP_SIZE

✅ 5. Extraction & navigation dans VARIANT / OBJECT / ARRAY

✔ Fonctions principales

  • FLATTEN — table function → exploser ARRAY/OBJECT en lignes
  • GET — accéder à une clé/une position
  • GET_PATH — extraction par chemin JSON
  • GET_IGNORE_CASE — accès insensible à la casse
  • : — opérateur JSON (ex. col:key)
  • OBJECT_KEYS — retourner liste des clés

Exemple conceptuel :

SELECT
    data:get.path.to.value,
    data:items[0]
FROM table;

✅ 6. Higher‑order functions (lambda)

Snowflake supporte des opérations fonctionnelles sur VARIANT/ARRAY :

  • FILTER — filtrer un ARRAY
  • TRANSFORM — transformation élément par élément
  • REDUCE — réduction (fold)
“See also Use lambda functions on data with Snowflake higher-order functions.”
