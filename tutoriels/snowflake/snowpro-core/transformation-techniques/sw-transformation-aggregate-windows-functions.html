Snowflake Aggregation Window Functions

1. Fonctions d'agrégation (Aggregation Functions)

✔ Définition

Une fonction d'agrégation opère sur plusieurs lignes et retourne une seule valeur.

“Aggregate functions operate on values across rows … and always return exactly one row, even when the input contains zero rows.”

✔ Catégories principales

1. Agrégation générale

Inclut les fonctions usuelles :

  • SUM, AVG, COUNT, COUNT_IF
  • MIN, MAX, MEDIAN, MODE
  • LISTAGG (concaténation)
  • CORR, COVAR_POP, COVAR_SAMP, etc.

2. Agrégations avancées

  • Bitwise : BITAND_AGG, BITOR_AGG, BITXOR_AGG
  • Booléennes : BOOLAND_AGG, BOOLOR_AGG, BOOLXOR_AGG
  • Semi‑structuré : ARRAY_AGG, OBJECT_AGG

3. Statistiques & Probabilités

  • KURTOSIS
  • SKEW

4. Estimation (HyperLogLog, MinHash, t‑Digest)

Important dans SnowPro Core :

  • APPROX_COUNT_DISTINCT (alias de HLL)
  • DATASKETCHES_HLL_*
  • APPROX_PERCENTILE, APPROX_TOP_K
✔ Particularités Snowflake (attention examen)
  • Certaines fonctions ont une syntaxe spéciale : PERCENTILE_CONT, PERCENTILE_DISC utilisent WITHIN GROUP.
  • Beaucoup d'alias existent (VAR_POP = VARIANCE_POP).
  • Entrée vide = généralement NULL, mais pas toujours (ex : COUNT(*) retourne 0).

2. Fonctions fenêtre (Window / Analytic Functions)

✔ Définition

“Window functions are analytic functions used for running totals, moving averages, rankings…”
  • Elles retournent une valeur par ligne, contrairement aux agrégations classiques.
  • Elles nécessitent ou peuvent inclure :
    • OVER ( … )
    • PARTITION BY
    • ORDER BY
    • Un window frame (ex : ROWS BETWEEN …).

3. Syntaxe OVER() — Composants essentiels

Source : Window Function Syntax 

<function>([args]) OVER (
    [PARTITION BY expr1, …]
    [ORDER BY expr2 [ASC|DESC] [NULLS FIRST|LAST], …]
    [window frame]
)

✔ PARTITION BY

  • Définit des groupes logiques (ex : par client, par jour).
  • Optionnel → une seule partition si absent.

✔ ORDER BY

  • Indispensable pour les fonctions de ranking.
  • Indépendant du ORDER BY final de la requête.

✔ Fenêtre (window frame)

Exemples :

  • ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
  • ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING
⚠️ Note : Snowflake ne supporte pas les positions ordinales dans OVER (ex : OVER (ORDER BY 1) interdit).

4. Types de fonctions fenêtre

✔ 1. Fenêtres générales

Incluent des fonctions qui existent aussi en agrégation :

  • SUM, AVG, COUNT, MIN, MAX
  • LISTAGG (avec WITHIN GROUP)
  • CORR, COVAR_POP/SAMP

La différence :

  • Agrégat → une seule ligne
  • Window → une sortie par ligne

✔ 2. Fonctions de ranking

  • ROW_NUMBER
  • RANK
  • DENSE_RANK
  • NTILE
  • PERCENT_RANK (limitation : supporte uniquement RANGE BETWEEN sans offset)

✔ 3. Fonctions de navigation (window navigation)

  • LAG
  • LEAD
  • FIRST_VALUE
  • LAST_VALUE
  • NTH_VALUE

Ces fonctions obligent un ORDER BY dans OVER.

✔ 4. Fonctions statistiques avancées

  • KURTOSIS
  • REGR_* (régression linéaire)

✔ 5. Fonctions semi‑structurées & bitwise

Certaines fonctions agrégées sont aussi compatibles sous forme fenêtre :

  • ARRAY_AGG, OBJECT_AGG
  • BITAND_AGG, BOOLAND_AGG

✔ Différence fondamentale

✔ QUALIFY

Même si non demandé, essentiel pour SnowPro :
QUALIFY filtre sur les résultats de fonctions fenêtre, comme HAVING filtre les agrégations.

✔ Particularités Snowflake
  • Beaucoup d'agrégations → version fenêtre avec OVER()
  • Certaines fonctions changent de comportement entre agrégat et window (ex. SUM)
  • DISTINCT interdit dans les window functions (ex : AVG(DISTINCT col) OVER() provoque erreur)

6. Résumé ultra‑rapide (Flashcards SnowPro Core)

✔ Agrégations

  • Toujours un seul résultat
  • Catégories : standard, booléenne, bitwise, semi‑structurée, estimation
  • Syntaxe spéciale : LISTAGG … WITHIN GROUP, PERCENTILE_CONT

✔ Window

  • Syntaxe obligatoire : OVER()
  • Composants : PARTITION BY, ORDER BY, Window Frame
  • Types : navigation, ranking, statistiques, agrégations fenêtre
  • DISTINCT interdit dans une window function
  • ORDER BY dans OVER ≠ ORDER BY final
