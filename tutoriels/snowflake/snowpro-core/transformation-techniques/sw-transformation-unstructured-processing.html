Snowflake - Unstructured Data with UDF & Procedures

Niveau Intermédiaire

Snowflake Unstructured Data Java

1. Objectif : lire & traiter des fichiers non structurés depuis Snowflake

Snowflake permet de :

  • Lire des fichiers non structurés (PDF, images, texte…) stockés sur un stage.
  • Appeler du code Java / Python / Scala via UDF, UDTF ou procédures pour analyser, transformer ou extraire du contenu.
  • S'appuyer sur les mécanismes sécurisés d'accès (Scoped URLs).
This topic provides examples of reading and processing unstructured data in staged files with handler code written in Java UDFs, UDTFs, and procedures.

2. Sécurité : utiliser impérativement une Scoped URL

Point MAJEUR pour SnowPro Core :

To make your code resilient to file injection attacks, always use a scoped URL when passing a file's location to a UDF.

✔ Pourquoi ?

  • Empêche l'utilisateur d'injecter des chemins non autorisés.
  • Limite l'accès au fichier au périmètre autorisé.
  • Les scoped URLs expirent automatiquement (24h).
  • Elles ne donnent pas de privilèges sur le stage.
⚠️ Les Scoped URLs doivent être générées via : BUILD_SCOPED_FILE_URL() (cité comme référence dans la page).

3. Accès au fichier dans les handlers UDF / Procedures

✔ Dans un UDF Java

The UDF handler reads the file using a Java InputStream.

➡️ Le fichier est lu via InputStream fourni par Snowflake.

➡️ Les UDF sont conçues pour renvoyer un résultat directement via SQL.

✔ Dans une procedure Java

The handler reads the file using a SnowflakeFile.

➡️ SnowflakeFile expose un accès plus riche (métadonnées, taille, etc.)

➡️ Adapté aux traitements complets ou multi‑étapes.

4. Exemple de traitement d'un PDF (donné dans la doc)

Snowflake montre un cas utilisant la bibliothèque Apache PDFBox :

Both handlers extract the contents of a specified PDF file using the Apache PDFBox library.

Le workflow présenté suit ces étapes :

  1. Télécharger la librairie PDFBox.
  2. L'uploader sur un stage interne.
  3. Écrire une UDF Java qui :
    • prend en entrée une scoped URL ;
    • lit le PDF via InputStream ;
    • extrait le texte.
  4. Écrire une procédure Java similaire utilisant SnowflakeFile.

CritèreUDFProcedure
Accès fichier InputStream SnowflakeFile

7. Support multi-langage

Handlers written in Python or Scala (UDFs, UDTFs, procedures).

Ce n'est pas limité à Java.

8. Bonnes pratiques (exigées pour SnowPro Core)

✔ Toujours passer une Scoped URL au handler

➡ Sécurité la plus importante.

✔ Stocker les dépendances (JAR / libs) dans un stage dédié

➡ Les UDF doivent IMPORT les fichiers depuis ce stage.

✔ Utiliser des stages différents :

  • un pour les librairies
  • un pour les données

✔ Préférer SnowflakeFile pour des opérations complexes

➡ plus de métadonnées ; meilleures performances.

✔ Vérifier le type MIME avant traitement

➡ utile pour éviter les erreurs (PDF, image, audio…).

9. Résumé en flashcards

✔ UDF = InputStream ; Procedure = SnowflakeFile.

✔ Toujours utiliser BUILD_SCOPED_FILE_URL pour l'accès fichier.

✔ Bibliothèques externes → stockées dans un stage.

✔ Unstructured data = accessible uniquement depuis un stage.

✔ Snowflake supporte Java, Python, Scala pour l'unstructured processing.
