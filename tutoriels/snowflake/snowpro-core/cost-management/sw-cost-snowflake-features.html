✅ 1. Understanding Overall Cost

Source :

Snowflake facture selon trois catégories principales :

✔ 1.1. Compute Cost

Les ressources compute consomment des crédits Snowflake.

Il existe trois types de compute :

🔹 Virtual Warehouse Compute

  • Ressource compute gérée par l'utilisateur.
  • Facturation à la seconde, minimum 60 secondes à chaque démarrage.
  • Utilisé pour :
    • exécuter requêtes SQL
    • charger des données
    • transformations (DML)

🔹 Serverless Compute

  • Ressources compute gérées automatiquement par Snowflake (ex. : Snowpipe, Search Optimization).
  • Snowflake ajuste la taille et le scaling automatiquement pour réduire le coût.

🔹 Cloud Services Compute

  • Utilisé pour : authentification, metadata, optimisation, accès, etc.
  • Gratuit tant que son usage ≤ 10% du coût compute quotidien.
  • Au-delà : facturation en crédits.

✔ 1.2. Storage Cost

  • Coût mensuel calculé selon un tarif fixe par téraoctet stocké.
  • Tarif différent selon :
    • Type de compte (Capacity vs On Demand)
    • Région
  • Calcul basé sur la moyenne quotidienne de stockage.

✔ 1.3. Data Transfer Cost

  • Pas de coût pour l'ingestion (data ingress).
  • Coût pour data egress :
    • transfert vers autre région
    • transfert vers autre cloud provider
    • tarif variable selon région / cloud
✔ 1.4. Rappel (SnowPro Core)
  • ➡ Le coût Snowflake = Compute + Storage + Data Transfer.
  • ➡ Compute = principal poste de dépense.
  • ➡ Cloud Services compute est facturé seulement au‑delà de 10% de l'usage compute quotidien.

✅ 2. Exploring Overall Cost

Source :

L'exploration des coûts Snowflake se fait via deux approches :

⭐ 2.1. Explorer les coûts dans Snowsight

Snowsight propose une interface graphique pour analyser les coûts :

✔ Informations importantes
  • Il peut y avoir un délai jusqu'à 72h avant l'affichage des coûts.
  • L'information est affichée en UTC, pas dans le fuseau horaire local.

✔ A. Organization Overview

Affiche :

  • Dépense totale depuis le début du contrat
  • Solde restant
  • Dépenses mensuelles
  • Contribution de chaque compte de l'organisation

Indisponible si :

  • l'organisation utilise des comptes On Demand
  • contrat via reseller

Pour y accéder :

  • Se connecter au compte organisation (ou rôle ORGADMIN activé)
  • Admin → Cost Management
  • Choisir un warehouse XS recommandé
  • Cliquer Organization Overview

✔ B. Account Overview

Affiche les coûts au niveau du compte :

  • consommation de crédits
  • répartition par type (compute, storage, data transfer, cloud services)
  • tendances dans le temps
Attention : Les ACCOUNTADMIN ne voient pas les coûts en monnaie sans le rôle ORGADMIN.

✔ C. Drilling Down into Costs

Snowsight permet d'explorer les coûts par :

  • warehouse
  • type d'usage
  • période
  • tags (pour répartition par BU, projet, environnement…)

⭐ 2.2. Explorer les coûts via SQL (ACCOUNT_USAGE et ORGANIZATION_USAGE)

Pour les analyses avancées :

  • METERING_HISTORY
  • METERING_DAILY_HISTORY
  • WAREHOUSE_METERING_HISTORY
  • CREDIT_USAGE_DAILY (selon édition/région)

Ces vues permettent :

  • analyses personnalisées
  • export vers BI
  • attribution des coûts par équipe / type d'usage
  • création de dashboards internes

✅ 4. Points clés à mémoriser pour l'examen SnowPro Core

🔹 Compute

  • principal composant de coût (warehouse + serverless + cloud services)
  • Cloud Services compute facturé uniquement au‑delà de 10% de l'usage compute quotidien

🔹 Storage

  • coût mensuel basé sur l'usage moyen quotidien

🔹 Data egress

  • coût lors de transferts multi‑régions ou multi‑cloud

🔹 Snowsight donne accès :

  • Organisation Overview
  • Account Overview
  • Drilldown par warehouse, usage type

🔹 Délais et fuseaux

  • Coûts affichés en UTC et jusqu'à 72h de délai

🔹 Rôle nécessaire

  • Le rôle ORGADMIN est nécessaire pour voir les coûts en devise
