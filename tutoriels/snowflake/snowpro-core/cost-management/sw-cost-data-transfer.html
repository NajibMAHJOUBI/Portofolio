Snowflake - Data Transfer Cost

Niveau Intermédiaire
Mis à jour: Février 2026 Durée: 20 min Difficulté: Intermédiaire
Snowflake Data Transfer Cost Management

🎯 Objectif

Comprendre comment Snowflake facture les transferts de données (data transfer), un élément-clé de la certification SnowPro Core.

1. Définition : qu'est‑ce que le Data Transfer ?

Le data transfer correspond au mouvement des données vers Snowflake (ingress) ou depuis Snowflake (egress).

  • Ingress = gratuit pour Snowflake.
  • Egress = payant sous certaines conditions.
Exception : votre fournisseur cloud peut facturer ses propres egress fees même si Snowflake ne le fait pas.

2. Quand les frais de Data Transfer s'appliquent‑ils ?

📌 2.1 Règle clé
Les coûts apparaissent uniquement lors de l'egress, c'est‑à‑dire lorsque les données sortent de Snowflake vers une autre région ou vers un autre cloud provider.
Transfert dans la même région = gratuit.

3. Opérations qui déclenchent des coûts de Data Transfer

Snowflake liste explicitement les actions suivantes comme génératrices de frais en cas de transfert cross‑region / cross‑cloud :

✔ Unloading Data

Exemple : COPY INTO <location> vers un bucket S3 / GCS / Azure situé dans une autre région ou un autre cloud.

✔ Database Replication

Réplication initiale + synchronisations régulières entre régions ou clouds.

✔ External Network Access

Appels externes depuis un UDF ou une procédure Snowpark via External Access.

✔ Copy Files entre Stages

Copier des fichiers entre stages situés dans des régions / clouds différents.

✔ External Functions

Transfert de données vers AWS / Azure / GCP via fonctions externes.

✔ Cross‑Cloud Auto‑Fulfillment

Diffusion de listings Marketplace Snowflake vers d'autres régions cloud.

✔ FileOperation.put via Snowpark

PUT vers un stage externe situé hors région.

⛔ Important : Les requêtes SQL récupérant des résultats à travers régions ne génèrent pas de frais d'egress selon les bonnes pratiques externes.

4. Comment Snowflake facture l'egress ?

📌 4.1 Facturation à l'octet

Snowflake facture un prix par octet transféré en egress.

Le tarif dépend du cloud provider et de la région où est hébergé le compte Snowflake.

Pour le détail des prix → Snowflake Pricing Guide

5. Comment analyser les coûts de Data Transfer ?

5.1 Via Snowsight

Snowflake permet de visualiser l'historique des transferts :

  • Menu : Admin → Cost Management → Consumption → Data Transfer
  • Unité : bytes transférés dans la plage temporelle sélectionnée.

5.2 Via les vues ACCOUNT_USAGE / ORGANIZATION_USAGE

6. Points clés à retenir pour l'examen SnowPro Core

✔ Snowflake ne facture pas l'ingestion (ingress)

✔ Data egress = payant uniquement lorsque les données quittent la région ou le cloud d'origine

✔ Exemples d'actions facturées : unloading, replication, external functions, cross‑cloud Marketplace, etc.

✔ Même si Snowflake ne facture pas l'ingress, le cloud provider peut facturer l'egress sortant de son stockage

✔ Analyse des coûts via :
  • Snowsight (dashboard Cost Management)
  • vues ACCOUNT_USAGE / ORGANIZATION_USAGE

✔ Les requêtes SQL récupérant des résultats cross‑region ne génèrent pas de frais d'egress
