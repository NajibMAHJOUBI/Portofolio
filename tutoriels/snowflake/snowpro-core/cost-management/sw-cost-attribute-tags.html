Snowflake Tags Cost Management

✅ 1. Objectif de l'attribution des coûts

L'attribution des coûts permet à une organisation de ventiler l'usage Snowflake vers des unités logiques internes :

  • départements
  • environnements
  • projets

Ce mécanisme sert au showback / chargeback, facilitant :

  • la comptabilité interne,
  • l'identification des sources de coûts,
  • la mise en place d'optimisations pertinentes.

✅ 2. Les mécanismes utilisés : Object Tags & Query Tags

✔ 2.1 Object Tags (Balises d'objet)

Ils permettent d'associer :

  • des ressources Snowflake (ex. warehouses, bases, users)
  • à des groupes logiques (departments, projects…).

Usage recommandé : Associer un warehouse à un département → le coût total du warehouse est attribué au département.

✔ 2.2 Query Tags (Balises de requête)

Indispensables lorsque :

  • une application exécute des requêtes pour plusieurs équipes,
  • des utilisateurs de multiples départements partagent les mêmes ressources.

Chaque requête reçoit un tag identifiant :
➡️ l'équipe / département / cost center.

✅ 3. Scénarios d'attribution courants

La documentation Snowflake décrit trois scénarios types :

Scenario 1 : Ressource utilisée par un seul département

Exemple : un warehouse dédié.

  • ✔ On attribue des object tags au warehouse.
  • ✔ 100% du coût est imputé au département.

Scenario 2 : Ressource partagée par plusieurs départements

Exemple : un warehouse utilisé par divers utilisateurs.

  • ✔ On attribue un object tag à chaque utilisateur.
  • ✔ Le coût est attribué en fonction des requêtes exécutées par utilisateur.

Scenario 3 : Application / workflow partagé

Exemple : requêtes exécutées par une application pour des utilisateurs variés.

  • ✔ On utilise les query tags pour associer chaque requête au bon département.

✅ 4. Création et gestion des tags

✔ 4.1 Scope des tags (compte unique vs organisation)

Lorsque vous configurez des tags, vous devez choisir s'ils s'appliquent à :

  • un seul compte Snowflake,
  • plusieurs comptes au sein d'une organisation Snowflake.
Règle clé :
  • Si les ressources d'un département sont dans un seul compte, créez les tags dans ce compte.
  • Si elles sont réparties sur plusieurs comptes, créez les tags dans un compte "central" et répliquez-les.

✅ 5. Pourquoi l'attribution des coûts est indispensable ?

Selon Snowflake, l'attribution des coûts améliore la visibilité :

  • Quel département consomme le plus de crédits ?
  • Quelle équipe génère les requêtes les plus coûteuses ?
  • Quels workloads nécessitent optimisation ?

Elle s'intègre dans la démarche globale de Cost Management (Visibilité → Contrôle → Optimisation).

✅ 6. Bonnes pratiques pour l'examen SnowPro Core

✔ Utiliser systématiquement object tags pour les ressources

(depuis les warehouses jusqu'aux utilisateurs).

✔ Utiliser les query tags pour tracer les pipelines, workflows et applications

(Utile lorsque plusieurs équipes partagent les mêmes ressources).

✔ Choisir le bon périmètre de création des tags

un compte ou plusieurs comptes (organisation).

✔ Bien comprendre les trois scénarios d'attribution

ressource exclusive, ressource partagée, application multi-départements

✔ Maîtriser le rôle des tags dans la ventilation réelle des coûts Snowflake
