Snowflake - Serverless Credit Usage

Niveau Intermédiaire
Mis à jour: Février 2026 Durée: 15 min Difficulté: Intermédiaire
Snowflake Serverless Cost Management

🎯 Objectif

Comprendre comment Snowflake facture les fonctionnalités serverless, ce qui est essentiel pour maîtriser l'optimisation des coûts dans le cadre de la certification SnowPro Core.

1. Qu'est‑ce que le Serverless Compute dans Snowflake ?

Snowflake propose deux formes de compute :

  • Virtual Warehouses — gérés par l'utilisateur.
  • Serverless Compute — géré automatiquement par Snowflake, sans intervention sur la taille, le provisioning ou le scaling.

Les fonctionnalités serverless incluent notamment :

  • Search Optimization Service
  • Materialized Views refresh
  • Automatic Clustering
  • Snowpipe (serverless variant)
  • Query Acceleration Service
  • Data Quality Monitoring

2. Comment Snowflake facture le Serverless Compute ?

📌 2.1 Unité de facturation : le compute‑hour

Snowflake mesure la consommation serverless en compute‑hours, une unité comparable aux ressources d'un warehouse XS fonctionnant pendant une heure.

🔎 Exemple :
Si Snowflake doit exécuter l'opération avec une capacité équivalente à un warehouse XL, alors :
XL = 16× XS
→ consommation = 16 compute‑hours / heure, donc 16 crédits pour une heure.

📌 2.2 Facturation automatique selon les ressources internes

  • L'utilisateur ne choisit pas la taille du compute.
  • Snowflake sélectionne dynamiquement la capacité nécessaire.
🔥 À retenir pour la certification :
La consommation serverless augmente proportionnellement avec les ressources nécessaires, même si cela n'est pas visible pour l'utilisateur.

3. Cloud Services Compute et Serverless

Snowflake sépare le compute en trois grandes catégories :

  • Virtual Warehouses
  • Serverless Compute
  • Cloud Services

📌 3.1 Cloud Services : conditions de facturation

  • Les Cloud Services (authentification, optimisation, compilation des requêtes…) sont facturés 4.4 crédits / heure,
  • mais seulement si leur consommation dépasse 10% de la consommation quotidienne en warehouses.

Cette règle vaut aussi pour les fonctionnalités serverless car elles utilisent la couche Cloud Services.

4. Comment Snowflake calcule les crédits serverless ?

📌 4.1 Règles de facturation

La consommation est calculée à la seconde et arrondie à la seconde la plus proche.

📌 4.2 Déclenchement de la consommation

→ Les crédits serverless sont consommés uniquement quand une fonctionnalité est réellement en action.

Exemples d'actions déclenchantes :

  • Recherche d'index interne pour Search Optimization
  • Rafraîchissement d'une Materialized View
  • Clustering automatique
  • Chargement automatique via Snowpipe

5. Risques et points d'attention pour la certification

⚠️ 5.1 Risque d'explosion des coûts

Les fonctionnalités serverless peuvent devenir coûteuses si :

  • le volume des données est très important,
  • les opérations se déclenchent fréquemment,
  • le fonctionnement n'est pas suivi dans les dashboards de consommation.

⚠️ 5.2 Absence de contrôle direct du compute

  • → Impossible de choisir la taille du compute serverless.
  • → Snowflake peut utiliser un niveau de capacité très élevé → hausse des crédits.

6. Points clés à mémoriser pour l'examen SnowPro Core

✔ Serverless = compute entièrement géré par Snowflake

✔ Facturation basée sur les compute‑hours, équivalent XS warehouse

✔ Snowflake peut utiliser plus de capacité (ex. XL → 16 crédits/h)

✔ Mesure au plus fin : facturée à la seconde

✔ Cloud Services facturés seulement au‑delà de 10% de la consommation quotidienne de warehouses

✔ Fonctionnalités concernées : Materialized Views, Auto Clustering, Search Optimization, Snowpipe, etc.

✔ Risque : coûts imprévisibles si absence de surveillance
