Snowflake Tasks Orchestration

✅ 1. Introduction aux Tasks Snowflake

Source : Introduction to tasks – Snowflake Documentation [docs.snowflake.com]

✔ Définition

Un task est un objet Snowflake permettant d'automatiser l'exécution de SQL (requêtes, DML, DDL, appels de procédures stockées).

Les tasks constituent un mécanisme interne pour orchestrer et planifier des pipelines de données.

✔ Modes de déclenchement

Un task peut être exécuté :

  • Selon un horaire (CRON, intervalle minutes / heures / secondes) [docs.snowflake.com]
  • Sur événement, notamment lorsque un stream contient de nouvelles données [docs.snowflake.com]

✔ Compute pour les tasks

Deux modèles disponibles :

  • Serverless Tasks : Snowflake alloue automatiquement les ressources nécessaires.
    • Taille max équivalente à XXLARGE WH.
    • Pas de paramètre WAREHOUSE dans CREATE TASK. [docs.snowflake.com]
  • User-Managed Warehouse : le task utilise un WH existant défini dans la commande.

✔ Cycle de vie d'un task

  1. Créer un rôle administrateur de tasks
  2. CREATE TASK pour définir le task
  3. Définir le compute, le schedule/trigger, les comportements d'erreur
  4. Tester via EXECUTE TASK
  5. Activer via ALTER TASK … RESUME
  6. Surveiller les coûts & logs (TASK_HISTORY, monitoring) [docs.snowflake.com]

✔ Task Graphs (DAG)

Les tasks peuvent être chaînés via AFTER pour créer des pipelines multi-étapes.

Snowflake gère exécution parallèle/série selon la logique. [docs.snowflake.com]

✔ Interaction avec les Streams

Les tasks peuvent automatiquement :

  • Identifier si un stream contient de nouvelles données (SYSTEM$STREAM_HAS_DATA)
  • Consommer ces changements pour transformer ou charger des données [docs.snowflake.com]

✅ 2. Commandes SQL liées aux Tasks

Source : Stream and task commands – Snowflake Documentation [docs.snowflake.com]

✔ CREATE TASK

Source détaillée : CREATE TASK – SQL Reference [docs.snowflake.com]

Syntaxe principale (simplifiée) :

CREATE [ OR REPLACE ] TASK [ IF NOT EXISTS ] <name>
    [ WAREHOUSE = <wh> | USER_TASK_MANAGED_INITIAL_WAREHOUSE_SIZE = <size> ]
    [ SCHEDULE = '<interval>' | 'USING CRON <expr> <tz>' ]
    [ AFTER <task_name> , ... ]
    [ WHEN <boolean_expr> ]
AS
    <sql_statement>;
🟦 Points clés à mémoriser pour SnowPro Core
  • Les tasks sont créés suspendus → il faut les activer avec ALTER TASK … RESUME. [docs.snowflake.com]
  • Plusieurs options importantes :
    • ALLOW_OVERLAPPING_EXECUTION
    • USER_TASK_TIMEOUT_MS (timeout)
    • SUSPEND_TASK_AFTER_NUM_FAILURES
    • WHEN (conditionnel)
    • AFTER (chaînage)
  • Pour les serverless tasks : pas de WAREHOUSE, Snowflake gère automatiquement. [docs.snowflake.com]

✔ ALTER TASK

Permet de :

  • Modifier le schedule
  • Modifier le WH ou la taille serverless
  • Activer/désactiver (RESUME / SUSPEND)
  • Modifier la condition WHEN [docs.snowflake.com]

✔ EXECUTE TASK

Permet d'exécuter manuellement un task pour test. [docs.snowflake.com]

✔ SHOW TASKS

Liste les tasks accessibles dans un schéma / base / compte. [docs.snowflake.com]

✔ DESCRIBE TASK

Affiche détails complets du task :

  • SQL exécuté
  • Schedule
  • Compute model
  • Dépendances (AFTER)
  • Configuration (WHEN, notifications, etc.) [docs.snowflake.com]

✔ DROP TASK

Supprime le task sans impacter les objets qu'il manipule.

✅ 3. Exemples essentiels

✔ Task simple (managed warehouse)

CREATE TASK load_hourly
WAREHOUSE = my_wh
SCHEDULE = '60 MINUTES'
AS
CALL process_new_data();

[docs.snowflake.com]

✔ Task serverless

CREATE TASK cleanup_serverless
SCHEDULE = '30 MINUTES'
AS
DELETE FROM audit_table WHERE event_ts < DATEADD(day,-7,current_timestamp());

[docs.snowflake.com]

✔ Activer un task

ALTER TASK load_hourly RESUME;

✅ 4. Points clés SnowPro Core à retenir

🔹 Tasks = Orchestrateur interne Snowflake

  • Automatisent SQL / procédures
  • Peuvent dépendre d'autres tasks (DAG)

🔹 Deux modes compute :

  • Warehouse géré
  • Serverless auto‑scalable

🔹 Créés suspendus → activation nécessaire

🔹 Fonctionnent très bien avec Streams (CDC)

→ Pipelines ELT continus

🔹 Commandes essentielles :

  • CREATE TASK
  • ALTER TASK
  • SHOW TASKS
  • DESCRIBE TASK
  • EXECUTE TASK
  • DROP TASK
