Snowflake Monitoring Query History

1. Snowsight Activity – Query History

Snowsight fournit une vue complète pour surveiller l'activité des requêtes, incluant :

✔ Quelles actions sont possibles ?

  • Visualiser les requêtes individuelles ou groupées exécutées dans le compte.
  • Voir les détails de performance d'une requête (durée, warehouse, statut).
  • Accéder au Query Profile pour examiner chaque étape du plan d'exécution.

✔ Période disponible

Snowsight affiche les 14 derniers jours d'exécution.

✔ Comment y accéder ?

Snowsight → Monitoring → Query History

✔ Privileges nécessaires

  • Vous pouvez toujours voir vos propres requêtes.
  • Pour les requêtes des autres utilisateurs :
    • ACCOUNTADMIN → visibilité totale.
    • Rôle avec MONITOR ou OPERATE sur un warehouse → visibilité sur les requêtes de ce warehouse.
    • GOVERNANCE_VIEWER → visibilité Grouped Queries mais pas Individual.

2. ACCOUNT_USAGE.QUERY_HISTORY (vue)

La vue SNOWFLAKE.ACCOUNT_USAGE.QUERY_HISTORY sert à auditer l'historique des requêtes sur 1 an (365 jours).

✔ Étendue et contenu

Elle retourne :

  • query_id, query_text, user_name, role_name
  • warehouse_name, warehouse_size, warehouse_type
  • query_type, session_id
  • Timestamps start et end
✔ Particularités
  • Contient également les requêtes de reader accounts, avec colonnes supplémentaires reader_account_name.
  • SQL text tronqué à 100 000 caractères.
  • Plus longue rétention que Information Schema (qui ne garde que 7 jours).

3. ACCOUNT_USAGE.QUERY_ATTRIBUTION_HISTORY (vue)

Cette vue permet d'attribuer les coûts de compute d'une requête, par warehouse.

✔ Colonnes essentielles

  • CREDITS_ATTRIBUTED_COMPUTE : crédits consommés pour exécuter la requête (hors idle time).
  • CREDITS_USED_QUERY_ACCELERATION : crédits QAS (Query Acceleration Service).
✔ Détails importants pour l'examen
  • La latence de mise à jour peut atteindre 8 heures.
  • Inclut coûts liés aux ajustements de taille (resizing) et autoscaling.
  • Ne comprend pas : data transfer, storage, cloud services, idle time, serverless features, AI token usage.

✔ Utilité

  • Calculer le coût par requête.
  • Analyser l'impact d'un workload sur un warehouse précis.
  • Faire de la refacturation interne.

4. INFORMATION_SCHEMA – QUERY_HISTORY table functions

Les fonctions QUERY_HISTORY(), QUERY_HISTORY_BY_USER(), QUERY_HISTORY_BY_SESSION(), QUERY_HISTORY_BY_WAREHOUSE() permettent d'obtenir l'historique des requêtes des 7 derniers jours, car elles s'appuient sur l'Information Schema.

✔ Syntaxe

SELECT *
FROM TABLE(information_schema.query_history(
    end_time_range_start => DATEADD('hour', -1, CURRENT_TIMESTAMP()),
    end_time_range_end => CURRENT_TIMESTAMP(),
    result_limit => 1000
));
✔ Points clefs
  • Limite à 7 jours, contrairement à ACCOUNT_USAGE (365 jours).
  • Paramètres optionnels :
    • RESULT_LIMIT (max 10000)
    • USER_NAME, WAREHOUSE_NAME, SESSION_ID selon la fonction
  • Peut inclure les requêtes en cours.

6. Points clés SnowPro Core à retenir

✔ Query History

  • Snowsight = 14 jours
  • Info Schema = 7 jours
  • Account Usage = 365 jours

✔ Query Attribution

  • Donne le coût compute attribué par requête
  • Ne compte pas l'idle time
  • Colonnes importantes : credits_attributed_compute, credits_used_query_acceleration

✔ Privileges

  • ACCOUNTADMIN → visibilité totale
  • MONITOR/OPERATE → visibilité warehouse
  • GOVERNANCE_VIEWER → accès aux vues d'audit (mais visibilité limitée dans Snowsight)

✔ Fonction QUERY_HISTORY

  • Limite 7 jours
  • Peut récupérer les requêtes en cours
  • Peut filtrer par user, warehouse, session

7. Mini‑FAQ utile pour l'examen

❓ Quelle vue utiliser pour analyser la consommation crédit par requête ?

→ ACCOUNT_USAGE.QUERY_ATTRIBUTION_HISTORY

❓ Comment récupérer les requêtes exécutées par un user précis sur les dernières heures ?

→ QUERY_HISTORY_BY_USER() via Information Schema

❓ Comment voir l'historique complet d'un compte sur 1 an ?

→ SNOWFLAKE.ACCOUNT_USAGE.QUERY_HISTORY

❓ Comment naviguer dans les requêtes dans l'UI ?

→ Snowsight → Monitoring → Query History
