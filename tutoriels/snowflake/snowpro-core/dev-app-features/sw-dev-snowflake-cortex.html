Niveau Intermédiaire
Mis à jour: Février 2026 Durée: 25 min Difficulté: Intermédiaire
Snowflake Cortex AI

✅ 1. Panorama des Snowflake AI & ML

Snowflake regroupe ses capacités "intelligentes" en deux familles : Snowflake Cortex (suite de fonctionnalités IA/LLM clé en main) et Snowflake ML (construire et opérer ses propres modèles). [docs.snowflake.com]

Cortex couvre notamment : Cortex Agents, Cortex AI Functions (incluant les ex‑LLM functions), Cortex Analyst, Cortex Fine‑tuning, Cortex Search, ainsi que des expériences comme Cortex Code (Snowsight/CLI) et Snowflake Intelligence. [docs.snowflake.com]

Principes de conception (IA) :
  • sécurité (modèles opérés dans le périmètre Snowflake),
  • confidentialité (Snowflake n'utilise pas vos données clients pour entraîner les modèles partagés),
  • contrôle via RBAC. [docs.snowflake.com]

Côté ML, Snowflake fournit des ML Functions prêtes à l'emploi (Forecast, Anomaly Detection, Classification, Top Insights) et des briques de MLOps (feature store, registry) pour les data scientists. [docs.snowflake.com]

✅ 2. Cortex AI SQL / AI Functions (AISQL)

2.1. Concept & positionnement

Cortex AI Functions est l'interface SQL/Python pour opérer des tâches IA sur texte/images (et autres formats) sans sortir les données de Snowflake ; les modèles (OpenAI, Anthropic, Meta, Mistral, DeepSeek, etc.) sont hébergés dans Snowflake pour la performance, l'échelle et la gouvernance. [docs.snowflake.com]

AI SQL regroupe et remplace/actualise les anciennes "LLM functions" sous une famille de fonctions AI_* (ex. AI_COMPLETE au lieu de COMPLETE, AI_EMBED au lieu de EMBED_TEXT_1024, etc.). [docs.snowflake.com]

2.2. Fonctions clés (exemples les plus courants)

  • Génération / complétion : AI_COMPLETE (génération texte ou image‑to‑text). [docs.snowflake.com]
  • Classification / filtrage : AI_CLASSIFY, AI_FILTER (booléen exploitable en WHERE). [docs.snowflake.com]
  • Agrégation IA cross‑lignes : AI_AGG, AI_SUMMARIZE_AGG (contournent la limite de contexte en opérant par lots agrégés). [docs.snowflake.com]
  • Embeddings : AI_EMBED pour vecteurs de similarité (recherche, clustering, RAG). [docs.snowflake.com]
  • Extraction structurée : AI_EXTRACT (texte/images/documents) pour schématiser des champs, tables, entités. [docs.snowflake.com]
  • Analyse de sentiment / traduction / résumé : AI_SENTIMENT, AI_TRANSLATE, SUMMARIZE. [docs.snowflake.com]
Astuce examen : les fonctions AISQL sont managées (task‑specific) et s'emploient en SQL standard (SELECT/WHERE/JOIN) ou en Python, toujours dans le compte Snowflake (pas d'orchestration externe requise). [docs.snowflake.com]

✅ 3. Cortex Analyst — Text‑to‑SQL géré pour l'analytique conversationnelle

3.1. Définition & objectifs

Cortex Analyst est un service géré (agentic LLM) qui convertit les questions en langage naturel en SQL précis sur vos données structurées Snowflake, puis exécute la requête et renvoie la réponse ; un REST API facilite l'intégration dans vos apps (chat interne, Streamlit, Slack/Teams, etc.). [docs.snowflake.com]

L'intérêt est d'éviter la complexité des architectures RAG "maison", de la gestion des modèles et du tuning, tout en offrant latence/coût maîtrisés et haute précision text‑to‑SQL. [docs.snowflake.com]

3.2. Fonctionnement & intégration

Vous interagissez avec Cortex Analyst via un REST endpoint (/api/v2/cortex/analyst/message) : vous fournissez la question et un semantic model (YAML ou semantic view) qui contextualise les métriques/dimensions, et le service renvoie SQL + réponse (streaming possible). [docs.snowflake.com]

Les custom instructions dans le YAML offrent un contrôle fin (arrondis, filtres par défaut, règles métier, instructions par module de la pipeline SQL). [docs.snowflake.com]

À retenir (exam) : Cortex Analyst ≠ simple LLM ; c'est un service text‑to‑SQL géré avec sémantique (YAML), RBAC, exécution dans le moteur Snowflake, et API‑first pour l'intégration. [docs.snowflake.com]

✅ 4. Cortex Search — Moteur de recherche hybride (RAG & enterprise search)

4.1. Définition & cas d'usage

Cortex Search fournit une recherche hybride (vector + keyword + sémantique) à faible latence directement sur vos données Snowflake, idéale pour RAG (chatbots enterprise) et enterprise search. [docs.snowflake.com]

Le service gère embeddings, index, refresh et qualité : vous créez un Cortex Search Service, puis requêtez via API (ou fonctions associées). [docs.snowflake.com]

4.2. Mise en route & écosystème

La doc fournit un exemple complet (création DB/WH/Service + jeu de données), ainsi que des tutoriels : app de recherche, chatbot avec LLM functions, chatbot PDF. [docs.snowflake.com]

À retenir (exam) : Cortex Search est complémentaire des AI Functions (pour embeddings/summarize/extract) et de Cortex Analyst (structuré) ; c'est souvent le moteur "R" d'un pipeline RAG dans Snowflake (recherche → contexte → génération). [docs.snowflake.com]

✅ 5. Différences clés (Cortex Analyst vs AI Functions vs Cortex Search)

  • AI Functions (AISQL) : primitives SQL/Python généralistes et spécialisées (complétion, classification, extraction, embedding, agrégations IA) pour opérer sur texte/images/documents dans Snowflake. [docs.snowflake.com]
  • Cortex Analyst : text‑to‑SQL géré pour données structurées ; s'alimente d'un semantic model YAML, expose un REST API et renvoie SQL + réponse. [docs.snowflake.com]
  • Cortex Search : recherche hybride managée pour RAG & enterprise search, gère embeddings/index/refresh pour texte non structuré et recherche contextuelle. [docs.snowflake.com]

✅ 6. Points "prêts‑à‑tomber" en SnowPro Core

  • Sécurité & gouvernance : modèles hébergés dans Snowflake, RBAC, données non utilisées pour entraîner des modèles publics. [docs.snowflake.com]
  • AISQL : préférez AI_* (nouvelles signatures) aux anciennes fonctions SNOWFLAKE.CORTEX. [docs.snowflake.com]
  • RAG dans Snowflake : Cortex Search (retrieval) + AI Functions (génération/synthèse/extraction) = pipeline complet in‑platform. [docs.snowflake.com]
  • Cortex Analyst : nécessite un semantic model (YAML/semantic view) ; intégration via REST. [docs.snowflake.com]
  • ML Functions ≠ Cortex : ML "traditionnel" (Forecast/Anomaly/Classification/Top Insights) avec coûts compute + stockage modèles. [docs.snowflake.com]

✅ 7. Mini‑mémento syntaxique (AISQL) — exemples conceptuels 

-- 1) Génération / transformation (texte)
SELECT AI_COMPLETE('Summarize the following text in French: ...') AS summary;
-- modèle géré dans Snowflake -- Réf. doc fonctionnalités : AI_COMPLETE dans AISQL

-- 2) Embeddings pour similarité
SELECT id, AI_EMBED(content) AS embedding FROM docs;
-- pour indexation / recherche vectorielle -- Réf. doc fonctionnalités : AI_EMBED

-- 3) Extraction structurée à partir de documents
SELECT AI_EXTRACT(file_col, '{ "fields": ["invoice_id","date","total"] }') AS struct FROM invoices;
-- Réf. doc fonctionnalités : AI_EXTRACT (documents/texte/images)

-- 4) Agrégation LLM multi-lignes (insights)
SELECT AI_AGG(text_col, 'List key themes and counts') AS insights FROM tickets;
-- Réf. doc fonctionnalités : AI_AGG / AI_SUMMARIZE_AGG

Remarque : la syntaxe exacte (paramètres, options de modèle, FILE type, etc.) est détaillée dans la page AISQL. [docs.snowflake.com]
