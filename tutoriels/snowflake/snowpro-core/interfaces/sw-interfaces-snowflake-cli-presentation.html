1. Qu'est-ce que Snowflake CLI ?

Le Snowflake CLI est l'outil officiel en ligne de commande pour :

  • interagir avec Snowflake via terminal,
  • automatiser les opérations,
  • créer et gérer des objets,
  • travailler avec Snowpark, Native Apps, Streamlit, packaging, etc.

Il est destiné à remplacer SnowSQL dans le long terme et fournit une expérience moderne de développement Snowflake.

2. Principales capacités du Snowflake CLI

1. Exécution de commandes SQL & Snowflake

  • Exécuter des requêtes SQL.
  • Gérer les comptes, utilisateurs, rôles, warehouses, objets.
  • Exécuter des scripts, automatiser via CLI.

2. Gestion du développement Snowflake

Le Snowflake CLI est un outil central pour :

  • Snowpark (Python, Java, Scala),
  • Snowflake Native Apps,
  • Streamlit apps hébergées dans Snowflake,
  • Projets Workspaces.

3. Packaging, déploiement & CI/CD

  • Build, package et déployer des applications Snowflake.
  • Intégration avec Git.
  • Support utilisé par les équipes DevOps / DataOps.

4. Support multi‑environnements

Permet d'utiliser :

  • environnements locaux
  • environnements cloud
  • authentification OAuth, key-pair, username/password

3. Points clés de la configuration

Installer le CLI

Le CLI est distribué via :

  • pip (Python)
  • installateurs spécifiques
  • conteneurs Docker

Création d'un fichier de configuration

Format YAML typique, contenant :

  • account
  • username
  • authentification
  • rôle
  • entrepôt par défaut
  • options de connexion

Authentification possible :

  • mot de passe
  • OAuth (recommandé)
  • clé privée
  • MFA / SSO

4. Commandes principales à connaître

Voici les familles de commandes à maîtriser :

  • snow sql : Exécuter une requête SQL depuis le terminal.
  • snow app : Créer, packager, valider et publier des Snowflake Native Apps.
  • snow snowpark : Outils pour développement Snowpark (Python, Java…).
  • snow function : Gérer les UDFs, Procedures et UDTFs
  • snow stage : Charger et gérer les objets stage.
  • snow deploy : Déployer des applications ou objets Snowflake.
  • snow login, snow connection : Gérer les connexions et tokens.

✅ 5. Fonctionnalités avancées

Gestion des secrets & credentials

  • stockage de secrets sécurisé
  • support de vaults externes

Intégration Git

  • possibilité de synchroniser projets Snowflake
  • support workflows CI/CD

Templates

Le CLI propose des modèles pour :

  • Snowpark
  • Native Apps
  • Streamlit
  • Projets de données
