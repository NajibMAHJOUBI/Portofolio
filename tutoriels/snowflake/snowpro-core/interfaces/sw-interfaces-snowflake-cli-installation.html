1. Présentation générale

Snowflake CLI est l'outil officiel en ligne de commande utilisé pour :

  • exécuter des requêtes SQL,
  • développer des apps Snowpark / Native Apps,
  • gérer des objets Snowflake,
  • automatiser des workflows DevOps.

Snowflake recommande d'utiliser des méthodes binaires, dont l'installateur Windows.

2. Pré‑requis avant installation

Avant d'installer Snowflake CLI, vous devez :

  • disposer d'un compte Snowflake valide,
  • disposer des privilèges nécessaires si vous souhaitez utiliser :
    • Streamlit in Snowflake,
    • Snowpark Container Services.
⚠ Attention avec la MFA

Si votre compte Snowflake impose la MFA, chaque commande CLI nécessite une approbation, sauf si vous activez le mécanisme de cache MFA (valable 4 heures).

3. Installation avec l'installateur Windows

On peut installer Snowflake CLI via l'installateur Windows.

Les étapes générales d'installation sont :

Étape 1 — Télécharger l'installateur Windows

  • Depuis le dépôt officiel Snowflake CLI (Snowflake CLI repository).

Étape 2 — Lancer l'installateur

  • Exécuter le fichier .msi téléchargé.
  • Suivre les étapes classiques (chemin d'installation, options, configuration).

Étape 3 — Vérifier l'installation

Une fois installé, vérifier avec la commande :

snow --help

4. Contenu de la commande snow --help

Les options générales du CLI (post‑installation) incluent notamment :

  • --version : afficher la version
  • --info : afficher les informations système du CLI
  • --config-file : spécifier un fichier de configuration
  • --install-completion : installer l'autocomplétion du shell

5. Vérification & tests post‑installation

Une installation réussie se confirme par :

snow --help
snow --version

Ces commandes permettent de valider que :

  • le binaire est accessible,
  • le PATH est correctement configuré.
