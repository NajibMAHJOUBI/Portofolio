1. Accéder à Snowsight

Snowsight est accessible via :

Internet public

  • Naviguer vers https://app.snowflake.com.
  • Fournir son account identifier ou sélectionner un compte déjà utilisé.
  • Choisir la méthode d'authentification puis se connecter.

Connexion via Private Connectivity

Utilisée dans les environnements à forte exigence de sécurité.

2. Pré-requis pour utiliser Snowsight

Warehouse requis pour certaines fonctionnalités

Certaines actions exécutent des requêtes (chargement, prévisualisation de données, Task Run History).

  • Snowflake recommande un warehouse X-Small pour ces opérations.
  • Toute requête exécutée via un warehouse consomme des crédits.

Optimisation des coûts

Il est recommandé d'appliquer des stratégies de réduction de coûts (auto-suspend, sélection du warehouse approprié, bonnes pratiques).

3. Authentification et sécurité

MFA (Multi‑Factor Authentication)

Snowflake encourage fortement l'utilisation de MFA.

  • Si un utilisateur n'a pas configuré MFA, Snowsight lui demande régulièrement (tous les 3 jours).
  • Des notifications Trust Center persistent tant que MFA n'est pas activée.

Activation MFA :

  • Sélectionner son nom d'utilisateur
  • Aller dans My Profile,
  • Section Multi-factor authentication → Enroll, puis suivre les instructions.
