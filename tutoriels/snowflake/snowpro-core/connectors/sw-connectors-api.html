API Integrations (CREATE API INTEGRATION)

Une API Integration est un objet Snowflake permettant à Snowflake d'appeler de manière sécurisée un service externe via HTTPS (AWS API Gateway, Azure API Management, Google API Gateway, Git repository APIs, etc.).

Ces intégrations sont principalement utilisées pour :

  • Les external functions,
  • Les services externes nécessitant une authentification IAM,
  • Les API REST privées exposées par une organisation.

1. Définition et rôle d'une API Integration

Une API integration Snowflake :

  • Contient les informations d'identité et d'accès permettant à Snowflake d'appeler une API externe (ex. rôle AWS, OAuth GitHub, audience Google…).
  • Définit les endpoints autorisés ou bloqués (API_ALLOWED_PREFIXES, API_BLOCKED_PREFIXES).
  • Sert à sécuriser la communication entre Snowflake et un proxy HTTPS externe (par ex. AWS API Gateway).

Elle est notamment utilisée par :

  • CREATE EXTERNAL FUNCTION (pour appeler une API depuis SQL).

2. Syntaxe et paramètres importants

La syntaxe dépend du fournisseur de l'API (AWS, Azure, GCP, Git).

Voici les paramètres communs :

✔ API_PROVIDER

Définit le fournisseur :

  • aws_api_gateway, aws_private_api_gateway, aws_gov_api_gateway, aws_gov_private_api_gateway
  • azure_api_management
  • google_api_gateway

✔ Identité & credentials

Selon le type d'API :

  • AWS : API_AWS_ROLE_ARN + éventuellement API_KEY
  • Azure : AZURE_TENANT_ID, AZURE_AD_APPLICATION_ID, API_KEY optionnel
  • GCP : GOOGLE_AUDIENCE
  • Git repository : Personal Access Token ou OAuth (support GA pour GitHub, preview pour autres providers)

✔ API_ALLOWED_PREFIXES / API_BLOCKED_PREFIXES

Liste des URLs autorisées ou interdites comme préfixes de requêtes.

Permet d'appliquer un filtrage strict des endpoints accessibles.

✔ ENABLED = TRUE|FALSE

Active ou désactive l'intégration.

3. Exemples de définitions

AWS API Gateway

CREATE API INTEGRATION my_api_int
    API_PROVIDER = aws_api_gateway
    API_AWS_ROLE_ARN = 'arn:aws:iam::12345:role/sf_api_role'
    API_ALLOWED_PREFIXES = ('https://abc123.execute-api.us-east-1.amazonaws.com/prod/')
    ENABLED = TRUE;

Azure API Management

CREATE API INTEGRATION my_api_int
    API_PROVIDER = azure_api_management
    AZURE_TENANT_ID = 'xxxx-xxxx'
    AZURE_AD_APPLICATION_ID = 'yyyy-yyyy'
    API_ALLOWED_PREFIXES = ('https://myapi.azure-api.net/v1/')
    ENABLED = TRUE;

Google Cloud API Gateway

CREATE API INTEGRATION my_api_int
    API_PROVIDER = google_api_gateway
    GOOGLE_AUDIENCE = 'https://my-gateway-service'
    API_ALLOWED_PREFIXES = ('https://my-gateway-123.gateway.dev/')
    ENABLED = TRUE;

4. Cas Git Repository (GitHub, GitLab…)

  • Support GA pour GitHub (OAuth).
  • Support preview pour les autres providers Git.
  • Permet d'utiliser un token ou l'OAuth pour accéder à une API Git.

5. Utilisation dans Snowflake

✔ 1. Création de l'intégration

→ via CREATE API INTEGRATION (objet de sécurité géré par ACCOUNTADMIN).

✔ 2. Contrôle des endpoints autorisés

→ grâce à API_ALLOWED_PREFIXES.

✔ 3. Consommation via External Functions

Exemple pour utiliser l'intégration dans une fonction externe :

CREATE EXTERNAL FUNCTION get_weather(city STRING)
RETURNS VARCHAR
API_INTEGRATION = my_api_int
URL = 'https://my-api/weather'
HEADERS = ('X-Custom-Key' = 'value');

(Les external functions ne sont citées que par référence dans la documentation API Integration)

✔ 4. Monitoring

→ SHOW API INTEGRATIONS

6. Sécurité et bonnes pratiques

  • Utiliser API_ALLOWED_PREFIXES comme périmètre minimal de sécurité.
  • Ne jamais autoriser un préfixe trop large.
  • Activer/désactiver via ENABLED = TRUE|FALSE.
  • Pour AWS : utiliser un IAM Role dédié et limiter les actions.

7. Points clés pour SnowPro Core

✔ Une API Integration permet à Snowflake d'appeler une API HTTPS externe en toute sécurité.

✔ Les identifiants d'accès (ARN, tenant ID, audience…) sont stockés dans l'intégration.

✔ La configuration impose un filtrage strict via API_ALLOWED_PREFIXES.

✔ L'intégration est utilisée principalement par les external functions.

✔ Providers supportés : AWS API Gateway, Azure API Management, Google API Gateway, Git repos APIs.

✔ Commandes associées :

  • CREATE API INTEGRATION
  • ALTER API INTEGRATION
  • DROP INTEGRATION
  • SHOW INTEGRATIONS
