✅ 1. Snowflake Connectors – Vue d'ensemble

Source : Snowflake Connectors

Les Snowflake Connectors sont des intégrations natives permettant de connecter Snowflake à diverses applications, services et systèmes de bases de données.

Ils offrent :

  • Accès instantané aux données sans développement d'intégration personnalisé
  • Ingestion automatique avec rafraîchissement selon votre fréquence
  • Support de l'historique + des modifications incrémentales

✔ Catégories principales de connecteurs fournis :

🔹 Connecteurs d'applications

  • Google Analytics GA4 – Aggregate : ingestion automatique des données agrégées GA4 (via Reporting API)
  • Google Analytics GA4 – Raw : ingestion automatique des événements GA4 bruts
  • Google Looker Studio : connecteur Snowflake permettant la visualisation directe dans Looker Studio
  • ServiceNow : ingestion des données ServiceNow dans Snowflake
  • SharePoint Online : ingestion de fichiers + permissions SharePoint, création automatique d'un service Cortex Search pour l'analyse avec AI Assistants

🔹 Connecteurs de bases de données

  • MySQL Connector : ingestion + réplication CDC MySQL vers Snowflake
  • PostgreSQL Connector : ingestion + CDC PostgreSQL vers Snowflake

✅ 2. Typologie des Connecteurs Snowflake

✔ 1. Connecteurs applicatifs

(GA4, Looker Studio, ServiceNow, SharePoint)

→ Permettent un accès natif aux APIs sources, une ingestion orchestrée par Snowflake et un rafraîchissement automatique.

✔ 2. Connecteurs de bases relationnelles

(MySQL, PostgreSQL)

→ Supportent ingestion + CDC (Change Data Capture) pour maintenir une copie synchronisée dans Snowflake.

✔ 3. Connecteurs via plateformes tierces

Exemples issus de l'écosystème (Airbyte, AWS Glue, Azure Data Factory, etc.).

→ Ces outils offrent des connecteurs natifs validés par Snowflake Ready Program.

✅ 3. Connecteurs dans l'Écosystème Snowflake

Source : Ecosystem Overview

Snowflake dispose d'un écosystème large regroupant :

  • Connecteurs développés par Snowflake
  • Connecteurs développés par des partenaires certifiés
  • Outils tiers validés pour fonctionner avec Snowflake

✔ Catégories de l'écosystème (vue officielle)

Data Integration (ETL / ELT)

Exemples : Airbyte, AWS Glue, Amazon Kinesis Firehose, Azure Data Factory, Alteryx, Boomi, Ascend.io…
→ Tous disposent d'un connecteur Snowflake ou d'une compatibilité native.

Business Intelligence (BI)

Tableau, Power BI, Looker, Qlik, Sigma…
→ Généralement via ODBC / JDBC / connecteurs directs.

Machine Learning & Data Science

Snowpark (Python, Java, Scala), Dataiku, H2O.ai, Databricks (via connecteurs), etc.

Security / Governance / Observability

Outils IAM, monitoring, audit, catalogage, lineage.

SQL Development & Management

Clients SQL compatibles (DBeaver, DataGrip, VSCode extensions).

Native Programmatic Interfaces

Drivers & clients Snowflake pour Python, Node.js, Java, .NET, JDBC, ODBC, SnowSQL, CLI, Snowpark.
→ Tout cela fait partie intégrante de l'écosystème officiel Snowflake.

✅ 4. Snowflake-provided Clients & Drivers (faisant partie de l'écosystème)

Source : Ecosystem Overview

✔ Clients et drivers fournis par Snowflake :

  • SnowSQL (CLI)
  • Snowflake CLI
  • Connecteurs programmatiques : Python, Java, Spark
  • Drivers : Node.js, JDBC, ODBC

Ces éléments servent d'interfaces standard pour se connecter à Snowflake depuis des applications, outils et pipelines.

✅ 5. Pourquoi les Connecteurs & l'Écosystème sont importants (SnowPro Core)

  • ✔ Intégration transparente avec systèmes sources
    → Snowflake s'intègre nativement avec d'innombrables outils grâce à un large éventail de connecteurs.
  • ✔ Réduction du coût d'ingestion
    → Les connecteurs automatisent l'extraction, la transformation légère et la synchronisation.
  • ✔ Écosystème robuste selon les cas d'usage :
    • ELT / Data Engineering
    • BI & Analytics
    • ML / AI workloads
    • Gouvernance et observabilité
  • ✔ Interopérabilité forte avec ODBC/JDBC
    → Couverture quasi universelle dans les outils du marché.

✅ 6. Points clés SnowPro Core à mémoriser

🔹 1. Catégories de connecteurs officiels Snowflake

  • GA4 (Aggregate + Raw)
  • MySQL & PostgreSQL
  • Looker Studio
  • ServiceNow
  • SharePoint

→ Tous nativement intégrés.

🔹 2. Le rôle central de l'écosystème

Snowflake fonctionne avec :

  • Solutions de Data Integration
  • Outils BI majeurs
  • Data Science & ML
  • Connecteurs programmatiques (Python, JDBC, etc.)

🔹 3. Les connecteurs garantissent :

  • Ingestion automatisée
  • Rafraîchissement incrémental
  • Compatibilité multi-API / multi-plateforme

🔹 4. Snowflake Ready Technology Validation Program

Certifie les connecteurs partenaires (ex : Airbyte, Alteryx).
