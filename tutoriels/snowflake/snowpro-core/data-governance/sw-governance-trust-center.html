✅ 1. Trust Center — Overview

Source : [docs.snowflake.com]

Le Trust Center est une interface Snowsight permettant d'évaluer, surveiller et réduire les risques de sécurité dans un compte Snowflake. [docs.snowflake.com]

✔ 1.1. Fonctionnement général

  • Le Trust Center exécute des scanners (liés à des packages de scanners) pour analyser votre compte Snowflake.
  • Chaque exécution de scanner produit des findings (détections ou violations), ou rien si aucun problème n'est détecté. [docs.snowflake.com]

✔ 1.2. Types de résultats

Les findings sont classés en deux catégories :

  • Detections : alertes informatives (ex : accès anormal).
  • Violations : non‑conformités identifiées par rapport aux bonnes pratiques (ex : MFA non activée). [docs.snowflake.com]

✔ 1.3. Cas d'usage courants

Le Trust Center aide notamment à :

  • vérifier que la MFA est activée pour les utilisateurs humains,
  • identifier des rôles sur‑privilégiés,
  • détecter les utilisateurs inactifs depuis 90 jours,
  • identifier les utilisateurs à risque,
  • détecter des anomalies d'accès. [docs.snowflake.com]

✔ 1.4. Notifications proactives

Le Trust Center permet de configurer des alertes de sécurité pour suivre des risques sans surveillance manuelle constante. [docs.snowflake.com]

✔ 1.5. Limitations

Reader accounts non supportés. [docs.snowflake.com]

✔ 1.6. Rôles nécessaires

Un utilisateur doit obtenir un rôle d'application :

Dans un organization account, l'octroi doit être effectué via GLOBALORGADMIN. [docs.snowflake.com]

✅ 2. Trust Center — Interface et onglets

Source : [docs.snowflake.com]

Le Trust Center comprend plusieurs onglets clés :

  • Overview : vue d'ensemble de la posture de sécurité du compte.
  • Violations : analyse détaillée, remédiation et cycle de vie des violations.
  • Detections : résultats des scanners informatifs.
  • Manage Scanners : gestion des packages (CIS Benchmarks, Threat Intelligence…).
  • Organization : visibilité trans‑comptes (uniquement org-level + avec rôle adéquat).

✅ 3. Trust Center — Getting Started

Source : [docs.snowflake.com]

✔ 3.1. Activer les packages de scanners

🔹 CIS Benchmarks Scanner Package

  1. Se connecter à Snowsight.
  2. Utiliser un rôle avec SNOWFLAKE.TRUST_CENTER_ADMIN.
  3. Navigation : Governance & security → Trust Center.
  4. Sélectionner un warehouse.
  5. Aller dans Scanner Packages → CIS Benchmarks.
  6. Cliquer sur Enable. [docs.snowflake.com]

🔹 Threat Intelligence Scanner Package

Procédure similaire :

  • Governance → Trust Center → Warehouse → Scanner Packages → Threat Intelligence → Enable. [docs.snowflake.com]

Les scanners de ces packages peuvent ensuite être :

  • activés / désactivés individuellement,
  • programmés avec un planning personnalisé. [docs.snowflake.com]

✅ 4. Exemples d'utilisation dans Getting Started

✔ 4.1. Vérifier que la MFA est activée

  1. Avoir activé le package CIS Benchmarks.
  2. Aller dans Violations.
  3. Rechercher « multi-factor authentication ».
  4. Sélectionner la violation Ensure MFA is turned on for human users.
  5. Suivre les recommandations de remédiation. [docs.snowflake.com]

✔ 4.2. Identifier les rôles sur‑privilégiés

Rechercher la violation :

  • Ensure that Snowflake tasks do not run with ACCOUNTADMIN or SECURITYADMIN. [docs.snowflake.com]

✅ 5. Exigences de rôles dans Getting Started

  • Les tâches d'activation et de gestion exigent : SNOWFLAKE.TRUST_CENTER_ADMIN
  • La visualisation : SNOWFLAKE.TRUST_CENTER_VIEWER
  • En mode organisation : GLOBALORGADMIN pour accorder les privilèges. [docs.snowflake.com]

✅ 6. Points clés pour SnowPro Core — À retenir absolument

🎯 Fonctionnement du Trust Center

  • Analyse automatisée via scanners.
  • Fournit detections, violations, remédiation.

🎯 Packages de scanners

  • CIS Benchmarks : posture de sécurité standard.
  • Threat Intelligence : détection proactive des risques.

🎯 Rôles & sécurité

  • TRUST_CENTER_VIEWER → lecture
  • TRUST_CENTER_ADMIN → configuration complète
  • Reader accounts → non supportés

🎯 Exemples classiques d'audit

  • MFA non activée
  • Rôles trop puissants
  • Comptes dormants
  • Accès anormaux

✅ 7. Résumé express (à mémoriser)

  • Le Trust Center sert à analyser automatiquement la sécurité du compte Snowflake via des scanners et expose les violations + detections. [docs.snowflake.com]
  • L'activation du Trust Center repose sur les Scanner Packages (CIS Benchmarks, Threat Intelligence). [docs.snowflake.com]
  • Les rôles essentiels sont TRUST_CENTER_ADMIN et TRUST_CENTER_VIEWER.
  • Le Trust Center permet de détecter des problèmes comme : MFA absente, comptes inactifs, rôles sur-privilégiés, accès anormaux.
