Snowflake Tagging Classification

✅ 1. Object Tagging — Introduction

Source : [docs.snowflake.com]

✔ 1.1. Qu'est‑ce qu'un tag ?

  • Un tag est un objet de schéma pouvant être associé à d'autres objets Snowflake.
  • Il fonctionne comme une clé–valeur (key-value pair).
  • La clé = nom du tag, la valeur = une chaîne de caractères définie lors de l'assignation. [docs.snowflake.com]

✔ 1.2. Caractéristiques principales des tags

  • Un objet peut avoir plusieurs tags simultanément.
  • Un même tag peut être appliqué à différents types d'objets (warehouse, table, colonne…).
  • Le même tag peut avoir des valeurs différentes selon les objets.
  • Les tags sont utiles pour :
    • gouvernance,
    • audit,
    • classification de données sensibles,
    • analyses d'usage. [docs.snowflake.com]

✔ 1.3. Tag Inheritance (Héritage)

Les tags sont hérités par les objets situés plus bas dans la hiérarchie.
➜ Exemple : un tag défini sur une table est hérité par toutes ses colonnes. [docs.snowflake.com]

✔ 1.4. Automatic Tag Propagation

La propagation automatique permet qu'un tag se propage :

  • ON_DEPENDENCY : lors d'une dépendance d'objet,
  • ON_DATA_MOVEMENT : lors de déplacement de données,
  • ON_DEPENDENCY_AND_DATA_MOVEMENT : les deux. [docs.snowflake.com]

✔ 1.5. Tag Replication & Cloning

  • Les tags et leurs assignations sont répliqués vers les comptes secondaires.
  • Le cloning conserve les tags appliqués aux objets clonés. [docs.snowflake.com]

✔ 1.6. Usages gouvernance

Les tags permettent :

  • d'identifier les objets contenant des informations sensibles (PII…),
  • d'auditer les objets tagués,
  • de coupler les tags avec des masking policies pour une gouvernance avancée. [docs.snowflake.com]

✅ 2. Sensitive Data Classification — Introduction

Source : [docs.snowflake.com]

✔ 2.1. Objectif

  • Identifier automatiquement les colonnes contenant des données sensibles.
  • Supporter la conformité : GDPR, HIPAA, PCI…
  • Faciliter les actions de gouvernance (tagging, masquage, filtrage). [docs.snowflake.com]
❗ Disponible uniquement en Enterprise Edition ou plus. [docs.snowflake.com]

✔ 2.2. Fonctionnement général

La classification :

  • scanne les noms de colonnes et échantillons de données,
  • identifie les informations sensibles,
  • applique des tags système automatiquement,
  • peut être automatisée via un classification profile. [docs.snowflake.com]

✅ 3. Core Concepts of Sensitive Data Classification

Snowflake classe chaque colonne détectée comme sensible via deux catégories :

✔ 3.1. Semantic Category

  • Exemples : NAME, ADDRESS, etc.
  • Décrit le type d'attribut personnel.
  • Snowflake fournit des catégories natives.
  • Possibilité de créer des catégories custom. [docs.snowflake.com]

✔ 3.2. Privacy Category

Définit le niveau de sensibilité :

  • IDENTIFIER
  • QUASI_IDENTIFIER
  • SENSITIVE [docs.snowflake.com]

✔ 3.3. Classification Tags (Système)

Snowflake utilise deux tags système pour annoter automatiquement les colonnes :

  • SNOWFLAKE.CORE.SEMANTIC_CATEGORY
  • SNOWFLAKE.CORE.PRIVACY_CATEGORY [docs.snowflake.com]

Ces tags peuvent être mappés vers des tags personnalisés (user‑defined tags).

✔ 3.4. Classification Profiles

Un classification profile définit :

  • la fréquence de classification,
  • l'âge minimum d'un objet avant classification,
  • l'application ou non des tags système,
  • l'application automatique de tag maps (tag custom ↔ tag system),
  • la possibilité d'utiliser des classifiers custom. [docs.snowflake.com]

✅ 4. Tag Mapping

Permet de lier les classifications système aux tags métier.

Exemples :

  • Si SEMANTIC_CATEGORY = NAME, alors ajouter automatiquement un tag pii = HIGHLY_CONFIDENTIAL. [docs.snowflake.com]

✅ 5. Gouvernance automatique

Avec classification + tagging automatique, Snowflake peut :

  • Taguer automatiquement des colonnes sensibles,
  • Appliquer ensuite masking policies via tags,
  • Étendre une gouvernance cohérente sur tout un modèle de données. [docs.snowflake.com]

✅ 6. Synthèse pour SnowPro Core

🎯 Object Tagging

  • Tag = clé–valeur pour annoter objets Snowflake.
  • Inheritance + propagation automatique.
  • Peut être utilisé pour cost tracking, security, data governance.
  • Peut être associé à masking policies. [docs.snowflake.com]

🎯 Sensitive Data Classification

  • Identifie automatiquement les colonnes sensibles.
  • Assigne des system classification tags.
  • Utilise semantic & privacy categories.
  • Peut être automatisé avec classification profiles.
  • Tag mapping disponible pour propager vers des tags métier. [docs.snowflake.com]

✅ 7. Résumé express (à mémoriser pour l'examen)

  • Object Tagging = tagging clé–valeur, inheritance, propagation, gouvernance.
  • Les tags peuvent être appliqués à n'importe quel objet Snowflake.
  • Les tags sont utilisés pour classification, audit, sécurité et masquage.
  • Sensitive Data Classification = classification automatique + application des system tags.
  • Deux systèmes de catégories : semantic et privacy.
  • Peut déclencher automatiquement des policies via tag‑mapping.
